At each stage: read the mapped sections → reconstruct the kernel / derivation from blank (the meat — yours) → master the load-bearing 20% cold → invoke the listed command. The When column is your trigger; don't read ahead of the build. Sections are from the MEAP TOCs (CUDA v05 · RLHF v04).

Ch 4 (naive CUDA matmul → cuBLAS) → Ch 6.6 (the GEMM ladder: coalescing → shared-mem tiling → 1D/2D blocktiling → vectorize) → FA (Ch 8) → quant (Ch 9).
🟣 RLHF spine — SFT → RM → RL → DPO
Ch 4 (SFT) → Ch 5 (reward modeling) → Ch 6 (RL / GRPO) → Ch 8 (DPO). Over-optimization (Ch 14) = your RQ2 home turf; Regularization/KL (Ch 15) = monitors.py.

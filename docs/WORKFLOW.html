🔁 Reconstruct, don't copy

⚙️ Engineer
agents scaffold · you predict
  • /kernel-day pulls today's ONE rung + the % target
  • bench-writer writes the failing test + the bench.py roofline call — the DoD

✍️ Implement
the meat — you only
  • Reconstruct the kernel from blank in your editor
  • Stuck → /tutor — hints + the book chapter, never code
  • The kernel-write-guard hook blocks any agent from writing it

🚀 Execute
measure the truth
  • Run → make the test pass (correctness first)
  • /profile → roofline-analyst: BOUND · WHY · NEXT ← the DoD
  • Break it — remove the optimization, watch it degrade
  • /kreview → ACCEPT/REJECT · is the speedup real?
the profile is done, not the green test
🧠 Master
lock it in
  • Teach-back cold — explain why it works, from physics
  • Can't? → loop back to Predict (you haven't mastered it)
  • Stumble → ledger → spaced re-test (Leitner +2/+4/+7d)
predict-before-run + teach-back = mastered
↻ master → engineer the next rung  ·  one loop = one kernel, fully understood

C

How it compounds & how it sticks

🎯 Mastery gate
Advance only when you can predict the roofline before running AND teach the mechanism cold. Otherwise re-loop. A green test with no profile does not close the day.
🧷 Retention
Every stumble → the ledger with a cause tag + next_test date. Cold pass → +2/+4/+7d; fail → +1d. Sunday = a cold re-test of the whole ladder from blank.
🪜 Reliance drill
One session/week, work read-only (--permission-mode plan): read the profile and form your own bottleneck hypothesis before the analyst. Catches quiet skill erosion.

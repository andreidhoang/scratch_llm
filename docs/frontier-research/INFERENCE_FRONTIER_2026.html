Precision & quantization — the TCO lever

~99% of serving TCO is the electricity to power the chips, and decode is memory-bound — so operand bits dominate $/token. This is the layer where the frontier moved fastest in 2026.

What the frontier runs

›FP8 — the standard training + serving precision (DeepSeek-V3 trained in FP8).
›NVFP4 — Blackwell-native 4-bit float, two-level (per-block + per-tensor) scaling, ~2× efficiency, ~1.8× memory vs FP8, <1% PTQ accuracy loss; FP4 weights shipped for Llama 3.x/4 + DeepSeek-R1/V3.
›Quantized KV — KIVI (per-channel key / per-token value, 2-bit) and FP8-KV, the primary cost lever past long context.

What the project owns

✓bf16 mixed precision + the fp16-accumulation lesson (built).
◐FP8 fake-quant numerics study + INT4 weight/activation fake-quant lab — per-channel scaling, the outlier blow-up, the TCO framing (CPU-buildable).
○NVFP4/FP4, FA3/FA4, real FP8 GEMMs — need Blackwell/Hopper silicon → know-it. The fake-quant labs carry the intuition; the kernels are awareness.
Honest boundary: the project can teach why low-precision works and reproduce the numerics on CPU, but cannot run the real Tensor-Core paths without Blackwell/Hopper. That is the correct scope for a rental-commodity-GPU build — and the interview answer (current vs delayed scaling, per-tensor vs per-block, e4m3-fwd/e5m2-grad) is fully owned.

The decode-kernel frontier — DELTA

The one axis where the project aims past the production frontier rather than tracking it.

The gap DELTA targets

›Linear-attention models (GatedDeltaNet, Mamba-2, DeltaNet) sit <1 FLOP/byte at batch-1 decode — more memory-bound than attention. The full recurrent state round-trips HBM every token.
›NVIDIA released GDN-2 training + prefill kernels — but no decode kernel and no checkpoint. The decode regime is genuinely open.
›DELTA: a fused, state-resident decode kernel (restructure ~5 HBM passes → 1 read + 1 write), Triton-first (the win is traffic, not tensor cores), targeting ≥85% of the measured H100 memory roofline.
›Discipline: P1–P7 falsifiable predictions + kill criteria committed before any kernel code; e2e is projected via Amdahl (no checkpoint). MFU is explicitly an anti-goal.

Why a hiring committee reacts

It is the exact layer the current production wave is decode-bound on, measured honestly, on a regime even NVIDIA leaves open — and it sits on the A2 infrastructure (the Phase-1 harness is the A2 systems finish), so the spike and the base share work rather than competing.

Verdict & gaps

For a from-scratch portfolio, the inference touch is excellent and frontier-aligned: it owns the fundamentals, scopes production infra honestly, and goes deeper than the frontier on one axis (decode kernels).

Where it matches or exceeds the frontier

✓Fundamentals owned from scratch — FA2 kernel + roofline, KV-cache, quant numerics, the serving seam, train↔infer drift. Exactly what a 2026 inference RE is screened on, built not imported.
✓DELTA goes past the frontier on linear-attention decode — the open regime. A measured roofline there is a genuine differentiator.
✓Honest scoping — Dynamo-class orchestration, PD-disaggregation, and FP4-on-Blackwell are correctly know-it, with the OSS PR lane as the real on-ramp instead of reinventing infra.

The honest gaps

○Hardware-gated: NVFP4/FP4 and FA3/FA4 need Blackwell/Hopper — not buildable on rental commodity GPUs. The fake-quant numerics labs carry the intuition.
○Production orchestration: no multi-node disaggregated-serving system (correct call), but the OSS PR is still unshipped — the concrete next move for the systems door.
○Minor not-yet-covered: prefix/prompt caching (RadixAttention) and constrained/structured (grammar-guided) decoding — real serving features, currently absent even as labs.
◐Execution, not design: paged-KV, spec-decode, MLA, and DELTA itself are designed/labbed but not yet built. The gap is shipping, not knowing.
